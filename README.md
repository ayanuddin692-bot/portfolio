# Ayan Uddin — HTML5 & CSS3 Digital Marketing Portfolio

A responsive personal portfolio built with semantic HTML5 and CSS3. A small vanilla JavaScript file powers the mobile navigation, contact-form handoff, and current year. No React, Vite, build step, or package installation is required.

## Project structure

```text
ayan-uddin-html-css-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── robots.txt
├── sitemap.xml
└── README.md
```

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.
3. No `npm install` is needed.

## Before publishing

1. In `js/script.js`, replace `YOUR_EMAIL@example.com` with the email address where you want inquiries sent.
2. Replace `https://example.com/` in `index.html`, `robots.txt`, and `sitemap.xml` with your real HTTPS domain.
3. A WhatsApp button can only be configured once you provide your real number in international format. No phone number has been invented in this project.
4. If you need form submissions delivered automatically without opening the visitor's email app, connect a trusted form service or a backend. This static form does not pretend to submit messages to a server.
5. The sample portfolio cards are explicitly labelled demonstration concepts. Replace them with verified work when available.
6. The blog section links to `http://ayanuddin.free.nf/`. If your hosting supports HTTPS, update it to the HTTPS URL.
7. Review metadata and add real project images, certifications, and contact details only when verified.

## Deploy

Upload the contents of this folder (not the ZIP itself) to the public web root of a static hosting provider or your web host's `public_html` folder. Enable HTTPS, then update the canonical URL and sitemap to the final domain.

## Included

- Responsive sticky navigation and mobile menu
- Hero and service sections
- About, working principles, portfolio demonstration cards, 7 Cs, workflow, blog, and contact sections
- SEO title, meta description, Open Graph metadata, canonical placeholder, and Person JSON-LD
- `robots.txt` and `sitemap.xml` templates
- Keyboard focus styles and reduced-motion support

## Important

The canonical URL, sitemap, and robots sitemap URL use `example.com` placeholders. Replace them before launch. The website does not claim fabricated client results, certifications, testimonials, or awards.
